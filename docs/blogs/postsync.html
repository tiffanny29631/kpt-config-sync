What is PostSync?

PostSync is an experimental feature in kpt-config-sync that allows you to run custom actions after your resources have been synchronized.

Experimental Window: We are collecting feedback and improvement requests for PostSync until 12/31 this year.
If the feature is actively used and proves useful, we will support it in Config Sync.
Otherwise, this feature may be removed after the evaluation period.

Example

See the ./examples/postsync directory for a working example.
